# hapagg 的目标清单：每行一台 HAProxy 的 stats socket。
#
# 前提：各台的 haproxy.cfg 里有（注意 `*` 表示监听所有地址，生产上建议
# 换成内网地址，并用防火墙/安全组把 9999 限制在监控网段内）：
#
#     stats socket ipv4@*:9999 level admin expose-fd listeners
#
# 关于 level：hapagg **只发 show stat / show info 两条只读命令**，
# `level user` 就够用。上面写 admin 是因为很多现场本来就是这么配的
# （expose-fd listeners 是为无缝 reload 准备的，与监控无关）。
# 能收就把它降到 user——TCP stats socket 没有任何鉴权，admin 意味着
# 任何能连上 9999 的人都可以停服务、改权重、下线后端。
#
# 支持的写法（可混用）：
#   10.0.0.11:9999            地址:端口
#   10.0.0.12                 省略端口 → 用 -p 指定的默认端口（默认 9999）
#   名字 = 10.0.0.13:9999     起个名字，视图里按名字显示
#   [2001:db8::5]:9999        IPv6 必须加方括号
#   10.0.0.20-24:9999         末段区间，展开成 5 台
#   # 注释；行内 # 之后的内容也会被忽略

# ---- 北京一区 ----
bj-1 = 10.0.0.11:9999
bj-2 = 10.0.0.12:9999

# ---- 上海一区（一整段连号的机器）----
sh = 10.1.0.20-24:9999        # 会展开成 sh-1 … sh-5

# ---- 单独一台老机器 ----
legacy = 10.9.0.7:9999
