## 1. 通用约定

### 1.1 角色与地址

| 角色 | 进程 | 默认端口 | 基址 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| 节点 | `rl-limiter` | 8090（`RL_CONSOLE_PORT`） | `http://<节点>:8090` | 每台服务器一个，执行限速、采集监控 |
| 总控 | `rl-fleet` | 8095（`RL_CONSOLE_PORT`） | `http(s)://<总控>:8095` | 汇总多台节点、分配总带宽；第三方集成入口 |

- 协议：节点 HTTP；总控 HTTP，配置 `RL_TLS_CERT` / `RL_TLS_KEY` 后为 HTTPS。
- 读接口无鉴权，部署时须由防火墙/安全组限制来源。

### 1.2 编码与单位

- 请求/响应体：`application/json; charset=utf-8`。写接口的请求体必须是 JSON 对象。
- 时间：unix 秒（浮点或整数，UTC）。总控查询参数另接受 ISO 8601。
- 带宽单位：

| 位置 | 单位 |
| ---- | ---- |
| 节点快照、节点落盘、Prometheus（`*_bytes_per_s` / `*_bytes_per_second`） | bytes/s |
| 节点快照 `regulation` 段、节点配置（`*_mbps`）、总控全部字段 | Mbps（10⁶ bit/s） |

  换算：`Mbps = bytes/s × 8 ÷ 1e6`。

### 1.3 鉴权

请求头二选一：

```
X-API-Token: <令牌>
Authorization: Bearer <令牌>
```

| 凭据 | 适用 | 来源 | 权限 |
| ---- | ---- | ---- | ---- |
| 节点令牌 | 节点写接口 | 节点 `rl-limiter.env` 的 `RL_API_TOKEN`（`install.sh --token`） | 节点全部写接口 |
| 总控管理员令牌 | 总控写接口 | 总控 `rl-fleet.env` 的 `RL_API_TOKEN`（`install.sh --fleet --token`） | 总控全部写接口 + 管理 API 密钥 |
| 总控 API 密钥 | 总控写接口 | 管理员创建（`POST /api/keys` 或页面「开放 API」） | 创建时授权的范围 |

总控 API 密钥的范围：

| 范围 | 允许的接口 |
| ---- | ---- |
| `limits` | `PUT/DELETE /api/total-quota`、`PUT/DELETE /api/nodes/{name}/limit` |
| `nodes` | `POST /api/nodes`、`PUT/DELETE /api/nodes/{name}`、`POST /api/nodes/import` |

**令牌强度规则**（节点令牌、总控管理员令牌、总控里登记的节点令牌通用；
规则实现见 `rl_limiter/tokenpolicy.py`）：

| 规则 | 要求 |
| ---- | ---- |
| 字符集 | `A-Z a-z 0-9 . _ ~ + / = -` |
| 长度 | 32 ~ 256 |
| 理论强度 | 长度 × log2(用到的字符集大小) ≥ 128 bit（纯十六进制至少 32 位） |
| 分布 | 香农熵 ≥ 2.5 bit/字符，不同三元组占比 ≥ 75% |
| 人为痕迹 | 不得含 ≥8 位同字符或顺序字符、短片段循环、常见弱词（password/secret/token/admin/fleet/limiter/server/production 等） |

不达标的令牌**一律视为未配置**：节点/总控写接口返回 403；总控里登记的
节点令牌作废（该节点只读观测）；安装脚本拒装。推荐生成方式：
`install.sh --token auto`，或 `openssl rand -hex 32` 生成后经 `--token ask` / `--token -` 交给安装脚本（§2.3）。

### 1.4 错误格式

所有错误响应：

```json
{"error": "<中文原因>"}
```

`error` 是给人看的完整说明（含怎么改），客户端可直接展示。状态码汇总见 §7。

### 1.5 跨域与嵌入

| 能力 | 节点 | 总控 |
| ---- | ---- | ---- |
| iframe 嵌入 | 不限制 | **不限制**（不发 `X-Frame-Options` / `frame-ancestors`）；只读精简页 `/?embed=1&tab=<overview\|nodes\|history\|logs>` |
| 浏览器跨域调用 | 不支持 | `RL_CORS_ORIGINS` 白名单内的来源：预检 `OPTIONS` 返回 204，响应带 `Access-Control-Allow-Origin`；其余来源预检 403 |

被 HTTPS 页面嵌入时，总控须为 HTTPS（浏览器混合内容规则）。

## 2. 安装脚本 `install.sh`（命令行接口）

### 2.1 获取

```bash
curl -fL -o install.sh https://github.com/ipest-info/haproxy_ingress_rate_limiter/releases/latest/download/install.sh
```

也随发布包分发（`rl-limiter-<tag>-linux-x86_64.tar.gz` 解开后的 `install.sh`）。
需要 root。

### 2.2 用法

```
install.sh [--download [TAG]] [--token TOKEN|ask|-|auto] [--client-nic NIC]
           [--backend-nic NIC] [--node-name NAME] [--advertise ADDR]
install.sh [--download [TAG]] --fleet [--token TOKEN|ask|-|auto]
install.sh --show-join [--node-name NAME] [--advertise ADDR]
install.sh --uninstall [--fleet] [--purge]
install.sh --help
```

| 模式 | 触发 | 作用 |
| ---- | ---- | ---- |
| 安装节点 | 默认 | 二进制 + 节点配置 + `rl-limiter.service`；要求双网卡 |
| 安装总控 | `--fleet` | 二进制 + 总控配置 + `rl-fleet.service`；不查网卡 |
| 补打接入串 | `--show-join` | 读已装节点的 env 打印接入串，不装不改 |
| 卸载 | `--uninstall` | 停服务、（节点）清 tc 规则、删单元，见 §2.6 |

### 2.3 选项

| 选项 | 适用 | 参数 | 说明 | 默认 |
| ---- | ---- | ---- | ---- | ---- |
| `--download [TAG]` | 安装 | 可选 tag（`v0.6.6` 或 `0.6.6`） | 从 GitHub Release 下载发布包（校验 sha256）后用包内 install.sh 安装；不带 tag = 最新版 | 用当前目录的发布包 |
| `--token TOKEN` | 节点 / 总控 | 令牌、`ask`、`-` 或 `auto` | 写入 `RL_API_TOKEN`，须过强度规则（§1.3）。`<令牌>` = 直接给值（会进 shell 历史与 `ps`）；`ask` = 终端交互输入，不回显、输两次、不达标当场重输（最多 3 次）、直接回车 = `auto`；`-` = 从标准输入读一行（去行尾回车与首尾空白；标准输入是终端时同 `ask`）；`auto` = 生成 64 位十六进制并在结束时打印 | 不设（写接口禁用） |
| `--client-nic NIC` | 节点 | 网卡名 | 客户端侧网卡（入向限速执行），写入 `RL_TC_IN_IFACE` | `eth0` |
| `--backend-nic NIC` | 节点 | 网卡名 | 后端服务侧网卡，写入 `RL_BACKEND_IFACE`；与客户侧相斥 | `eth1` |
| `--node-name NAME` | 节点 / `--show-join` | `[A-Za-z0-9._-]{1,64}` | 接入串里的节点名 | 短主机名 |
| `--advertise ADDR` | 节点 / `--show-join` | 主机、主机:端口 或 `http(s)://…` | 接入串里总控访问本节点控制台的地址 | 后端侧网卡 IPv4 + 控制台端口 |
| `--fleet` | 安装 / 卸载 | — | 作用于总控 | 节点 |
| `--show-join` | — | — | 只打印接入串 | — |
| `--uninstall` | — | — | 卸载 | — |
| `--purge` | 卸载 | — | 连该角色的配置一起删 | 保留配置 |
| `-h`, `--help` | — | — | 打印用法 | — |

带值的选项支持 `--opt 值` 与 `--opt=值` 两种写法；值以 `-` 开头时只能用后者。

影响行为的环境变量：`PREFIX`（默认 `/usr/local`）、`CONF_DIR`（默认
`/etc/rl-limiter`）、`UNIT_DIR`（默认 `/etc/systemd/system`）。

### 2.4 安装前校验（任一不通过：退出码 1，不写任何文件）

| 校验 | 适用 | 失败信息要点 |
| ---- | ---- | ---- |
| root 权限 | 全部（`--help` 除外） | `需要 root` |
| 参数合法 | 全部 | `不认识的参数` / `需要一个值` / `不合法` |
| 双网卡（物理网卡 ≥ 2，`/sys/class/net/*/device`） | 节点安装 | `节点要求双网卡……不允许安装` |
| 客户侧、后端侧网卡存在且不是同一张 | 节点安装 | `不存在` / `不能是同一张` |
| 令牌强度 | 给了 `--token` | `令牌太短` / `令牌强度不足：<原因>`；`-` 没读到内容：`标准输入里没读到令牌`；`ask` 没有终端：`需要在终端里交互运行` |
| 版本 tag 格式 `v<主>.<次>.<补丁>[-rcN]` | `--download TAG` | `不符合 tag 规则` |
| 选项组合 | 全部 | `--fleet` 不收 `--client-nic/--backend-nic/--node-name/--advertise`；`--show-join` 只收 `--node-name/--advertise`；`--uninstall` 不收 `--download/--token/--*-nic/--node-name/--advertise`；`--purge` 只配 `--uninstall` |
| 下载与 sha256 | `--download` | `查询最新版本失败` / `下载失败` / `sha256 校验失败` |

### 2.5 输出

- 过程日志：标准输出，每行前缀 `install.sh: `；告警与错误在标准错误
  （`install.sh: 注意：…` / `install.sh: 错误：…`）。
- 节点安装成功时，最后**单独一行**（无前缀）打印接入串（格式见 §5.1）：

  ```
  rl-node name=edge-sh-07 url=http://10.0.1.21:8090 token=c0fa…
  ```

- `ask` / `-` 给的令牌不回显、结束时也不打印（节点的接入串里照常带 token）。
- `--download` 时令牌经标准输入交给下载的 install.sh（不进它的命令行）；
  `ask` 在下载完成后提问，用包里的 `rl-limiter` 做完整校验。包内脚本是不支持
  这种交接的老版本（v0.6.6 及更早）时退回命令行传递并告警。
- `--token auto` 时：节点令牌包含在接入串里；总控令牌以
  `install.sh: 总控令牌（…）：<令牌>` 打印一行。
- 安装**不自动启动**服务：核对配置后 `systemctl enable --now rl-limiter`
  （或 `rl-fleet`）。升级 = 重跑 install.sh（二进制覆盖、配置不动）+ `systemctl restart`。

### 2.6 退出码

| 码 | 含义 |
| ---- | ---- |
| 0 | 成功（含 `--help`、`--show-join`、`--uninstall`） |
| 1 | 校验失败或执行出错（标准错误给出原因） |

`--download` 时退出码为包内 install.sh 的退出码。

### 2.7 写入的文件

| 路径 | 节点 | 总控 | 规则 |
| ---- | ---- | ---- | ---- |
| `$PREFIX/bin/rl-limiter`、`rl-fleet` | ✓ | ✓ | 每次覆盖 |
| `$CONF_DIR/config.yaml` | ✓ | | 已存在不覆盖；`660 root:rl-limiter` |
| `$CONF_DIR/rl-limiter.env` | ✓ | | 已存在不覆盖，只改命令行给出的项；`640 root:rl-limiter` |
| `$CONF_DIR/fleet.yaml` | | ✓ | 同上；`660` |
| `$CONF_DIR/rl-fleet.env` | | ✓ | 同上；`640`；缺 `RL_METRICS_LOG` 时补上 |
| `$UNIT_DIR/rl-limiter.service` / `rl-fleet.service` | ✓ | ✓ | 每次覆盖 |

卸载（`--uninstall`）：节点先 `systemctl disable --now rl-limiter`，再按
`rl-limiter.env` 清客户侧网卡 ingress qdisc、删 IFB 设备（默认
`ifbrl0`）、接了出向整形时撤 HTB 根；删单元；另一角色也不在才删二进制；
`--purge` 删该角色配置。保留 `/var/log/rl-limiter` 与用户 `rl-limiter`。

### 2.8 示例

```bash
# 节点：自动生成令牌，指定网卡
sudo bash install.sh --download --token auto --client-nic ens33 --backend-nic ens34
# 总控
sudo bash install.sh --download --fleet --token auto
# 手动设置令牌：交互输入（不回显）/ 从标准输入读
sudo bash install.sh --download --token ask --client-nic ens33 --backend-nic ens34
sudo bash install.sh --download --fleet --token - < /root/fleet.token
# 在节点上补打接入串
sudo bash install.sh --show-join --advertise 10.0.1.21
# 卸载节点并删除配置
sudo bash install.sh --uninstall --purge
```

### 2.9 venv 装法脚本 `deploy/bare/rl-limiter.sh`

| 子命令 | 说明 |
| ---- | ---- |
| `install` | 前置检查（python3 ≥ 3.9、tc、HTB、systemd、双网卡）→ 建用户 → venv → 配置 → 校验 → 内核调优 → systemd → 启动并核对 |
| `check` | 只检查不改，有问题退出码 1 |
| `start` / `stop` / `restart` / `status` / `logs` | 服务操作 |
| `uninstall` | 删服务；保留配置、venv、tc 规则（打印手工清理命令） |

## 3. 节点 rl-limiter HTTP 接口

### 3.1 一览

| 方法 | 路径 | 鉴权 | 说明 |
| ---- | ---- | ---- | ---- |
| GET | `/api/overview` | 无 | 服务与配置视图 + 最新快照 |
| GET | `/api/history` | 无 | 近 10 分钟快照（1 秒一拍） |
| GET | `/api/stream` | 无 | 实时快照（SSE） |
| GET | `/api/logs` | 无 | 运行日志增量 |
| GET | `/api/tc` | 无 | tc 实况 |
| GET | `/api/config-view` | 无 | 配置页数据 |
| GET | `/api/openapi.json` | 无 | 本节 OpenAPI 描述 |
| GET | `/metrics` | 无 | Prometheus 指标（§5.4） |
| PUT | `/api/instance-quota` | 节点令牌 | 设实例出向总目标 |
| DELETE | `/api/instance-quota` | 节点令牌 | 取消实例出向总目标 |
| PUT | `/api/request-limits/{name}` | 节点令牌 | 登记/修改端口入向限速 |
| DELETE | `/api/request-limits/{name}` | 节点令牌 | 删除端口入向限速 |

写接口未配置节点令牌（或令牌强度不足）时整体返回 403。修改整份校验后
原子回写节点 YAML，数秒内热生效。

### 3.2 GET /api/overview

响应：

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| `service_version` | string | 版本 |
| `config_version` | integer | 配置内容校验和（变化 = 热更过） |
| `uptime_s` | number | 运行秒数 |
| `frontends` | object | 端口登记视图：`{名: {bind_port, quota_mbps, quota_bytes_per_s, …}}` |
| `request_limits` | object | 入向限速登记：`{名: {mbps, conn_rate}}` |
| `instance_quota_mbps` | number | 实例出向总目标（Mbps；0 = 不限） |
| `instance_quota_bytes_per_s` | number | 同上换算为 bytes/s |
| `instance_quota_executable` | boolean | 本机是否有实例总目标的执行者；false 时 PUT 返回 409 |
| `haproxy` | object | 数据源视图 `{name, endpoint, unix, degraded}`（键名为历史兼容保留；`degraded` = 采样失联） |
| `latest` | object\|null | 最新快照，结构见 §3.3 |

### 3.3 GET /api/history

响应 `{"snapshots": [快照, …]}`。快照：

| 字段 | 说明 |
| ---- | ---- |
| `ts` | 采样时间 |
| `config_version` | 采样时的配置校验和 |
| `units` | 按端口的应用层观测（通用形态恒为空对象） |
| `instance` | 整机观测，见下表 |
| `haproxy` | 同 overview |
| `regulation` | 闭环调节视图（Mbps，仅闭环工作时存在），见下表 |

`instance`：

| 字段 | 说明 |
| ---- | ---- |
| `conn` / `active_conns` / `idle_conns` / `max_conn` | 并发连接 |
| `conn_new_ps` / `conn_denied_ps` | 每秒新建 / 拒绝连接 |
| `nic` | 锚点网卡名（客户侧） |
| `nic_rate_in_bytes_per_s` / `nic_rate_out_bytes_per_s` | 锚点网卡入/出（网卡口径，与计费一致） |
| `pkts_in_ps` / `pkts_out_ps` / `drop_in_ps` / `drop_out_ps` | 锚点网卡包速率与丢包 |
| `nics[]` | 逐卡 `{name, rate_in_bytes_per_s, rate_out_bytes_per_s, pkts_in_ps, pkts_out_ps, drop_in_ps, drop_out_ps}` |
| `rate_in_bytes_per_s` / `rate_out_bytes_per_s` | 应用层口径（通用形态为 0） |
| `degraded` | 采样失联 |

`regulation.instance`：

| 字段 | 说明 |
| ---- | ---- |
| `target_mbps` | 实例出向目标 |
| `gate_mbps` | 入向总闸当前值（null = 全开） |
| `gate_max_mbps` | 总闸上限 |
| `ingress_mbps` | 最近一轮实测流入（null = 暂无） |
| `egress_mbps` | 出向观测（10 秒均值，网卡口径） |
| `egress_source` | `nic` 或 `haproxy`（回退） |
| `landed` | 是否已按实测流入落位 |

### 3.4 GET /api/stream

`text/event-stream`，每拍一条 `data: <快照 JSON>`；连接建立先补发最新一帧。

### 3.5 GET /api/logs

| 参数 | 位置 | 说明 |
| ---- | ---- | ---- |
| `after` | query，整数 | 上次拿到的最大 `seq`；缺省 0 |

响应 `{"logs": [{"seq", "ts", "level", "msg"}]}`（进程内最近 1000 条）。

### 3.6 GET /api/tc · GET /api/config-view

- `/api/tc`：`{"sections": [{key, title, iface, desired, help[], raw: [{label, note, text}]}]}`；
  限速未接线时 `{"sections": [], "disabled_reason": "…"}`。
- `/api/config-view`：`{"yaml_path", "sections": [...]}`；section 为只读
  `{title, hint, kv: [{label, value}]}` 或可编辑 `{title, hint, rows: [{label, sub, fields: [{name, label, value, api: {method, url, key}}], del?}]}`。

### 3.7 PUT /api/instance-quota

| 项 | 内容 |
| ---- | ---- |
| 鉴权 | 节点令牌 |
| 请求体 | `{"quota_mbps": <number ≥ 0>}`（Mbps；0 = 取消） |
| 响应 | `{"ok": true, "instance_quota_mbps": <number>}` |
| 错误 | 400 参数不合法；401；403；409 本机没有执行者（`instance_quota_executable=false`） |

```bash
curl -X PUT http://10.0.1.11:8090/api/instance-quota \
  -H "X-API-Token: $NODE_TOKEN" -d '{"quota_mbps": 40}'
```

### 3.8 DELETE /api/instance-quota

取消实例出向总目标（恢复不限）。无请求体。响应
`{"ok": true, "instance_quota_mbps": 0}`。即使本机没有执行者也放行。

### 3.9 PUT /api/request-limits/{name}

| 项 | 内容 |
| ---- | ---- |
| 鉴权 | 节点令牌 |
| 路径参数 | `name`：端口登记名（YAML `ports` 段的键，须已登记） |
| 请求体 | `mbps`（number ≥ 0，0 = 不限带宽）与 `conn_rate`（integer ≥ 0，新建连接/秒，0 = 不限）**至少一个**；只给一个时另一个保留现值 |
| 响应 | `{"ok": true, "frontend": "<name>", "request_limit": {"mbps": …, "conn_rate": …}}` |
| 错误 | 400（参数不合法 / 端口未登记）；401；403 |

```bash
curl -X PUT http://10.0.1.11:8090/api/request-limits/fe_main \
  -H "X-API-Token: $NODE_TOKEN" -d '{"mbps": 10, "conn_rate": 150}'
```

### 3.10 DELETE /api/request-limits/{name}

响应 `{"ok": true, "frontend": "<name>", "removed": true|false}`
（`removed` = 是否真的删掉了一条登记）。

### 4.2 GET /api/overview

| 字段 | 说明 |
| ---- | ---- |
| `service_version` / `uptime_s` | 版本、运行秒数 |
| `total_quota_mbps` | 总流出带宽目标（0 = 未做总量控制） |
| `allocation` | 分配参数（只读） |
| `latest` | 最新快照：`ts`、`total_quota_mbps`、`egress_mbps`、`ingress_mbps`、`allocated_mbps`、`nodes_online`、`nodes_total`、`nodes`（见下表） |

`latest.nodes.<名>`：

| `controllable` | 是否有有效令牌 |
| `release_pending` | 已取消总量控制但限速尚未解除 |

### 4.3 GET /api/nodes

`{"nodes": [{"name", "url", "console_url", "has_token", "token_weak", "fixed_mbps"}]}`。
令牌只给有无（`has_token`）与是否因强度不足作废（`token_weak`）。

### 4.4 GET /api/metrics-log

| 参数 | 说明 | 缺省 |
| ---- | ---- | ---- |
| `from` / `to` | unix 秒或 ISO 8601（不带时区按总控本机时区） | 最近 1 小时 |
| `kind` | `fleet`、`node`、`event` 的逗号组合 | 全部 |
| `node` | 只看该节点（事件保留该节点的与全局的） | — |
| `limit` | 最多返回行数（≤ 50000） | 20000 |
| `format` | `jsonl` = 以附件下载原始行 | JSON |

响应 `{"rows": [...], "truncated": bool, "files": n, "start": …, "end": …}`；行格式见 §5.3。
未启用监控落盘时 404。

### 4.5 GET /api/whoami

响应 `{"actor": "admin" | "key:<名>", "scopes": [...]}`——管理员为
`["limits", "nodes", "keys"]`，API 密钥为它被授权的范围。凭据无效 401。

### 4.6 PUT /api/total-quota

| 项 | 内容 |
| ---- | ---- |
| 范围 | `limits` |
| 请求体 | `{"quota_mbps": <number，0 ~ 10⁷>}`（0 = 取消总量控制） |
| 响应 | `{"ok": true, "total_egress_mbps": <number>}` |
| 效果 | 立即按需重新分配；按需节点分 `总带宽 − Σ固定限速 − 冻结记账` |

```bash
curl -X PUT https://fleet:8095/api/total-quota -H "X-API-Token: $KEY" -d '{"quota_mbps": 1000}'
```

### 4.7 DELETE /api/total-quota

取消总量控制：立即解除各**按需**节点的实例出向目标（恢复不限），离线的
恢复在线后解除；固定限速的节点不受影响。响应
`{"ok": true, "total_egress_mbps": 0}`。

### 4.8 PUT /api/nodes/{name}/limit

| 项 | 内容 |
| ---- | ---- |
| 范围 | `limits` |
| 请求体 | `{"mbps": <number，(0, 10⁷]>}` |
| 响应 | `{"ok": true, "name": "<name>", "fixed_mbps": <number>}` |
| 语义 | 该节点实例出向目标固定为 `mbps`：照值下发、不参与按需分配、计入总量记账；与总量控制无关（总带宽 0 时同样生效） |
| 错误 | 400（`mbps` 不是正数；取消请用 DELETE）；401；403；404 节点不存在 |

### 4.9 DELETE /api/nodes/{name}/limit

取消固定限速：在做总量控制 → 回到按需分配；没在做 → 解除该节点限速。
响应 `{"ok": true, "name": "<name>", "fixed_mbps": 0}`。

### 4.10 POST /api/nodes

| 项 | 内容 |
| ---- | ---- |
| 范围 | `nodes` |
| 请求体 | `{"name": "<[A-Za-z0-9._-]{1,64}>", "url": "http(s)://<节点>:<端口>", "token"?: "<节点令牌>", "console_url"?: "<跳转地址>"}` |
| 响应 | `{"ok": true, "name": "<name>"}` |
| 错误 | 400（字段不合法、令牌强度不足）；401；403；409 重名 |

没有 `token` = 只读观测（汇总可见，不分配、不下发）。

### 4.11 PUT /api/nodes/{name} · DELETE /api/nodes/{name}

- PUT 请求体：`url`、`token`、`console_url` 中要改的字段（`token: ""` =
  清除）；名称不可改。响应 `{"ok": true, "name": …}`；404 节点不存在。
- DELETE：停止轮询与下发，该节点配额保持现状。响应同上；404。

### 4.12 POST /api/nodes/import

| 项 | 内容 |
| ---- | ---- |
| 范围 | `nodes` |
| 请求体 | `{"text": "<接入串文本，一行一台>", "dry_run": true\|false}` |
| 响应 | `{"dry_run", "items": [{"line", "name", "url", "console_url", "has_token", "action", "changes", "error"}], "add", "update", "same", "error", "ignored_lines"}` |
| `action` | `add` 新增 / `update` 同名节点的地址或令牌变了（`changes` 列出字段） / `same` 无变化 / `error` 该行有错（`error` 说明） |
| 语义 | `dry_run` 只预览不写盘；正式导入跳过有错的行，其余一次原子写入；文本里不含接入串的行计入 `ignored_lines` |
| 错误 | 400（没有任何接入串 / 请求体不合法）；401；403 |

### 4.13 /api/keys

| 方法 | 请求 | 响应 |
| ---- | ---- | ---- |
| GET `/api/keys` | — | `{"keys": [{"name", "scopes", "created"}], "scopes": ["limits", "nodes"]}` |
| POST `/api/keys` | `{"name": "<名>", "scopes": ["limits"\|"nodes", …]}` | `{"ok", "name", "scopes", "token", "note"}`——`token` 只在此出现一次 |
| DELETE `/api/keys/{name}` | — | `{"ok", "name"}`，立即失效 |

只认管理员令牌（API 密钥调用返回 403）。错误：400 名称/范围不合法；409 重名；404 不存在。

## 5. 数据格式

### 5.1 接入串

节点安装后打印、总控 `POST /api/nodes/import` 与页面「粘贴接入串」解析：

```
rl-node name=<名称> url=<节点控制台地址> [token=<令牌>] [console=<页面跳转地址>]
```

- 一行一台；空格分隔 `key=value`（值不含空格；`=` 按第一个切分）。
- 行内 `rl-node ` 之前的内容忽略；不含 `rl-node ` 的行整行忽略。
- 字段：`name` 必填、`url` 必填（`http(s)://`）、`token` 可选（须过强度规则）、`console` 可选。

### 5.2 节点监控落盘（`RL_METRICS_LOG`，默认 `/var/log/rl-limiter/metrics.jsonl`）

JSONL，每分钟写一次，每天 UTC 零点轮转（旧文件追加 `.YYYY-MM-DD`），保留
`RL_METRICS_LOG_DAYS` 天。速率单位 bytes/s。

| kind | 字段 |
| ---- | ---- |
| `instance`（v=2） | `ts`、`samples`、`nic`、`rate_in_avg/max`、`rate_out_avg/max`（网卡口径）、`conn_new_pm`、`denied_pm`、`conn_max`、`drop_in_pm`、`drop_out_pm`、`degraded_s` |
| `frontend` | `ts`、`samples`、`name`、`rate_avg/max`、`rate_in_avg`、`conn_max`、`conn_new_pm`、`denied`、`mean10_max`、`quota`、`over_s`、`degraded_s` |

### 5.3 总控监控落盘（`RL_METRICS_LOG`，默认 `/var/log/rl-limiter/fleet-metrics.jsonl`）

轮转与保留同上，单位 Mbps。`GET /api/metrics-log` 读的就是它。

| kind | 写入时机 | 字段 |
| ---- | ---- | ---- |
| `fleet` | 每分钟 | `ts`、`samples`、`total_mbps`、`egress_avg/max`、`ingress_avg/max`、`allocated_mbps`、`nodes_online_min`、`nodes_total`、`over_samples` |
| `node` | 每节点每分钟 | `ts`、`name`、`samples`、`online_samples`、`egress_avg/max`、`ingress_avg/max`（整分钟离线为 null）、`quota_mbps`、`desired_mbps`、`release_pending`、`error`、`write_err` |
| `event` | 发生即写 | `ts`、`type` + 类型字段，见下表 |

`event.type`：

| type | 字段 | 含义 |
| ---- | ---- | ---- |
| `start` | `version`、`total_mbps`、`nodes` | 总控启动 |
| `total` | `from_mbps`、`to_mbps` | 总带宽变更 |
| `limit` | `node`、`from_mbps`、`to_mbps` | 节点固定限速变更（0 = 按需） |
| `quota` | `node`、`from_mbps`、`to_mbps` | 给节点下发实例出向目标成功 |
| `release` | `node`、`from_mbps`、`to_mbps`=0 | 解除节点限速成功 |
| `nodes` | `added`、`removed`、`changed` | 节点清单增删改 |
| `keys` | `added`、`removed` | API 密钥增删 |
| `api` | `by`（`admin` / `key:<名>`）、`op`、操作参数 | 开放 API 写操作审计 |

`api.op` 取值：`set_total`、`cancel_total`、`set_node_limit`、`clear_node_limit`、
`add_node`、`update_node`、`remove_node`、`import_nodes`、`create_key`、`revoke_key`。
令牌的值从不写入落盘。

### 5.4 节点 Prometheus 指标（`GET /metrics`）

文本格式，前缀 `rl_limiter_`，速率 `*_bytes_per_second`。

| 指标 | 标签 | 说明 |
| ---- | ---- | ---- |
| `rl_limiter_info` | `version`、`haproxy` | 恒为 1 |
| `rl_limiter_config_version` | | 配置校验和 |
| `rl_limiter_uptime_seconds` | | 运行秒数 |
| `rl_limiter_haproxy_degraded` | | 采样失联（1 = 失联） |
| `rl_limiter_haproxy_idle_percent` | | 数据源自报空闲率（有才输出） |
| `rl_limiter_instance_quota_bytes_per_second` | | 实例出向总目标 |
| `rl_limiter_instance_connections` / `_max_connections` / `_new_connections_per_second` | | 整机连接 |
| `rl_limiter_instance_rate_in/out_bytes_per_second` | | 应用层口径 |
| `rl_limiter_nic_rate_in/out_bytes_per_second` | | 锚点网卡（网卡口径） |
| `rl_limiter_nic_packets_in_per_second` / `rl_limiter_nic_drops_in_per_second` | | 锚点网卡包速率 / 丢包 |
| `rl_limiter_device_rate_in/out_bytes_per_second` | `nic` | 逐卡带宽 |
| `rl_limiter_device_packets_in/out_per_second` | `nic` | 逐卡包速率 |
| `rl_limiter_device_drops_in/out_per_second` | `nic` | 逐卡丢包 |
| `rl_limiter_frontend_quota_bytes_per_second` | `frontend` | 每个登记端口的限额（总输出） |
| `rl_limiter_frontend_*`（rate / rate_in / connections / new_connections / denied / over_quota / degraded / tc_*） | `frontend` | 按端口观测（有端口级采样时才输出） |

## 7. 状态码汇总

| 码 | 节点 | 总控 |
| ---- | ---- | ---- |
| 200 | 成功 | 成功 |
| 204 | — | CORS 预检通过 |
| 400 | 参数不合法；端口未登记 | 参数不合法；令牌强度不足；没有接入串；metrics-log 时间/kind 不合法 |
| 401 | 令牌缺失或不正确 | 令牌缺失或不正确；密钥已吊销 |
| 403 | 写接口未启用（未配置令牌或强度不足） | 范围不够；写接口未启用；API 密钥调密钥管理接口；CORS 来源不在白名单 |
| 404 | 路径不存在 | 路径不存在；节点/密钥不存在；监控落盘未启用（metrics-log） |
| 405 | 方法不支持 | 方法不支持 |
| 409 | 本机没有实例总目标的执行者 | 节点或密钥重名 |
